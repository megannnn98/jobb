# Тюнинг гиперпараметров: GPU1 → GPU2 → V2

## Конфигурации

Все версии обучены на одних данных: `aj_reviews_export.jsonl` (175K строк), сплит 80/10/10
(train/val/test), `MAX_LENGTH=128`, batch 64 (Phase 1) / 16 (Phase 2).

| Параметр | GPU1 (T4x2) | GPU2 (P100) | V2 (P100) |
|---|---|---|---|
| Unfrozen слоёв (Phase 2) | 2 | 2 | **4** |
| Phase 2 эпох | 1 | 2 | **3** |
| LR scheduler | linear | linear | **cosine + warmup 10%** |
| Early stopping | нет | нет | **macro F1, epoch** |
| Weight decay | 0 | 0 | **0.01** |
| Label smoothing | 0 | 0 | **0.1** |
| Gradient clipping | нет | нет | **1.0** |
| Class weights | да | да | да |
| Phase 1 LR / эпох | 5e-4 / 1 | 5e-4 / 1 | 5e-4 / 1 |
| Phase 2 LR | 2e-5 | 2e-5 | 2e-5 |

## Влияние каждого изменения

### 1. 4 unfrozen слоя (вместо 2)

**Ожидаемый эффект:** +capacity под специфику русского текста. RuBERT — 12-слойный,
2 слоя дают ~23M обучаемых параметров из 178M (13%), 4 слоя — ~45M (25%).
Больше слоёв = модель лучше адаптирует языковые паттерны к домену отзывов,
но растёт риск переобучения.

**Фактический эффект:** основной драйвер прироста. Positive precision выросла
с 0.628 до 0.683, manual_review F1 с 0.522 до 0.554. Модель стала лучше различать
нюансы тональности, особенно на малом классе positive.

**Риск:** без early stopping переобучилась бы — на 3-й эпохе валидационный F1
уже падал (0.749 → 0.746).

### 2. Warmup 10% + cosine decay

**Ожидаемый эффект:** стабильность сходимости в начале Phase 2 (после разморозки
слоёв градиенты большие). Cosine decay плавно снижает LR к концу обучения,
позволяя «дожать» оптимум без резких скачков.

**Фактический эффект:** ~0.2-0.3 п.п. macro F1. Без warmup модель иногда
«срывается» на первых шагах Phase 2 (residual loss spike), с warmup этого нет.
Cosine дал чуть лучший финальный оптимум по сравнению с линейным decay.

### 3. Early stopping (macro F1)

**Ожидаемый эффект:** предотвратить переобучение при увеличенном количестве
эпох и размороженных слоёв. Без него модель продолжает подгоняться под train
в ущерб обобщению.

**Фактический эффект:** сработал. Лучшая модель — epoch 2 (F1=0.749),
на epoch 3 F1 упал до 0.746. Без early stopping сохранилась бы худшая модель.

### 4. Weight decay 0.01

**Ожидаемый эффект:** базовая L2-регуляризация, которой не было в GPU1/GPU2.
Уменьшает норму весов, предотвращая overfitting на шумовых признаках.

**Фактический эффект:** умеренный. В комбинации с другими регуляризаторами
помогает держать веса в разумных пределах, особенно на малом классе positive.

### 5. Label smoothing 0.1

**Ожидаемый эффект:** calibration вероятностей, модель менее уверена в
предсказаниях, что помогает при threshold-based принятии решений. На macro F1
влияет слабо.

**Фактический эффект:** влияния на F1 почти нет (manual_review остался
на ~0.55). Но probabilities стали менее экстремальными — меньше случаев
confidence=0.99, что важно для threshold-политик.

### 6. Gradient clipping 1.0

**Ожидаемый эффект:** страховка от gradient explosion при разморозке 4 слоёв.
Без clipping нормы градиентов в Phase 2 иногда достигали 11-15, с clipping —
стабильно в пределах 1.0.

**Фактический эффект:** стабильность обучения, на метрики не влияет напрямую.

## Итоговые метрики (held-out test, 4000 сэмплов)

| Метрика | GPU1 | GPU2 | V2 | Δ V2-GPU2 |
|---|---|---|---|---|
| Accuracy | 0.808 | 0.815 | **0.825** | +1.0pp |
| Macro F1 | 0.705 | 0.710 | **0.733** | +2.3pp |
| Positive F1 | 0.705 | 0.714 | **0.748** | +3.4pp |
| Positive precision | 0.599 | 0.628 | **0.683** | +5.5pp |
| Negative F1 | 0.888 | 0.894 | **0.898** | +0.5pp |
| Manual review F1 | 0.523 | 0.522 | **0.554** | +3.2pp |

## Рекомендованные пороги (V2)

| Политика | neg_thr | pos_thr | precNeg | precPos | Покрытие |
|---|---|---|---|---|---|
| `balanced` | 0.55 | 0.90 | 0.930 | 0.844 | ~73% |
| `safe` | 0.70 | — | 0.920 | — | ~44% |

Политика `balanced` — дефолт для продакшена: авто-негатив с высокой точностью,
авто-позитив пороговый (precision 0.844, цель 0.90 не достигнута — позитив всегда
под ручным контролем модератора). `safe` — только уверенный негатив.

## Что не сработало

- **Больше эпох (4+):** без дополнительной регуляризации модель переобучается.
- **Focal loss:** не помогает для manual_review — проблема не в imbalance,
  а в пересечении текста с positive/negative (noisy label).
- **Увеличение MAX_LENGTH > 128:** сигнал сентимента в первых ~128 токенах,
  удлинение не даёт прироста.
